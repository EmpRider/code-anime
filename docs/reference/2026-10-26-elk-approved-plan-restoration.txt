## Goal and architecture

Render source-proven, visually distinguishable nested for/while, if/else, try/catch/finally scopes in DOWN and RIGHT orientations, with directed arrows between regions and all current user controls preserved. Use existing X6 Shape.HTML renderer for HTML cards, select inputs, interaction, arrows, labels, and accessibility. ELK.js version 0.12.0 calculates geometry inside a self-hosted, same-origin browser Worker; never run ELK layout on main thread as silent fallback. Preserve outer Dagre method placement and synchronous public diagram.render API with internally async, generation-guarded layout.

Preserve CodeGraph plus AI-labeled mock simulation data as sole source. Never execute, import, evaluate, instrument or compile/run analyzed user project code. Do not truncate prepared events or impose arbitrary total step caps. Keep shared cursor, source-line highlights, stack, variable/return values, mock console, breakpoints, visit/invocation native dropdowns, code-and-call action buttons, expand/collapse, focus/selection, pan/zoom, return arrows and user-supplied continuation.

Unsupported/ambiguous source must remain visible in prepared sequence with unknown labels, never invented group membership or solid executed branches. Color augments textual group type/status, shape/border/dash and arrowheads. Preserve script-src self and style-src self CSP and do not add blobs or inline scripts. If worker fails, warn accessibly and keep source, console, cursor and playback usable.
