## Current root-cause confidence

1. **Verified:** The browser's `securitypolicyviolation` recorder receives `style-src-elem` entries only after the real preview starts; the new test fails on an actual nonempty array. Worker/X6 readiness succeeds, so the original generic Worker layout-unavailable hypothesis no longer explains these four browser failures.
2. **Now strongly inferred but still unverified:** Upstream AntV X6 core may insert redundant inline CSS by default through module-global `Config.autoInsertCSS`, while the project's trusted same-origin `/vendor/x6.css` is byte-identical to upstream core CSS (2,854 bytes). Counts 3/7 correlate with Graph instances, **not source-linked attribution**. Exact event source, blocked URI, insertion stack, independently injected plugin CSS, and Config isolation from legacy/shared consumers remain unknown; a global flag change is **not yet authorized**.
